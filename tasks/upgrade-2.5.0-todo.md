# MCP Inspector 2.5.0 执行清单

> 权威规格：[`docs/UPGRADE-2.5.0.md`](../docs/UPGRADE-2.5.0.md)
>
> 详细任务：[`tasks/upgrade-2.5.0-plan.md`](./upgrade-2.5.0-plan.md)

## 产品确认

- [ ] 确认采用“报告批次 → 成员/调用列表 → 单一调用详情”。
- [ ] 确认成员可展开多个，但任何时刻只展示一个完整响应区。
- [ ] 确认普通执行自动保留历史，“保存报告”只创建命名版本与保留锁。
- [ ] 确认版本标签在同项目、同套件内唯一，例如 `1.0`、`2.0`。
- [ ] 确认 2.5.0 不做两个报告的字段级 Diff/并排比较。
- [ ] 确认历史查看只读，不自动覆盖 Tool 调试 Tab。

## Phase 1：报告读取骨架

- [ ] Task 1：锁定报告共享契约与确定性夹具。
- [ ] Task 2：提供套件执行历史稳定分页。
- [ ] Task 3：构建报告 Outline 聚合服务。

### Checkpoint A

- [ ] 任一套件历史可分页浏览。
- [ ] Outline 展示快照成员和调用摘要，不携带完整响应。
- [ ] 并发完成顺序不改变成员顺序。
- [ ] 项目、连接、套件、执行、测试执行和 Run 引用链隔离通过。
- [ ] 改名/删除当前定义后历史仍可读。

## Phase 2：保存报告版本

- [ ] 实现前重新确认下一可用迁移编号。
- [ ] Task 4：新增保存报告持久化与引用保护。
- [ ] Task 5：提供保存报告服务、API 和客户端方法。

### Checkpoint B

- [ ] 可以把终态执行保存为 `1.0` 和 `2.0`。
- [ ] 重复版本标签返回稳定冲突，不覆盖旧版本。
- [ ] POST 幂等和 PATCH revision 冲突行为通过。
- [ ] 保存版本不复制参数、响应或凭据。
- [ ] 被保存版本引用的执行链不会被历史清理破坏。
- [ ] 删除保存版本不删除普通执行历史。

## Phase 3：核心报告体验

- [ ] Task 6：抽取可复用的单次调用详情。
- [ ] Task 7：交付套件报告层级导航。
- [ ] Task 8：交付保存版本交互。

### Checkpoint C

- [ ] 单 Tool 成员可查看最终参数与完整响应视图。
- [ ] 场景多步骤、重试和清理调用均出现在展开列表中。
- [ ] 默认定位首个失败调用；全通过时定位首个可查看调用。
- [ ] 8 个并发成员时状态和时间准确，成员顺序稳定。
- [ ] 任一时刻最多挂载一个完整 `RunResultPanel`。
- [ ] 运行中无 Run 的项不会显示伪造详情。
- [ ] 快速切换项目/套件/报告/调用时没有迟到响应串入。
- [ ] 保存表单冲突或失败时保留输入。

## Phase 4：完整入口与性能

- [ ] Task 9：集成测试报告页的测试套件视图。
- [ ] Task 10：收口实时轮询、缓存、取消和性能。

### Checkpoint D

- [ ] 测试用例报告现有行为无回归。
- [ ] 套件页和测试报告页打开同一权威报告内容。
- [ ] 普通历史与保存版本视觉和语义明确。
- [ ] 100 成员 × 20 调用的 Outline 首屏不会请求全部 Run。
- [ ] 列表和详情滚动所有者明确，窄屏可使用。
- [ ] 项目切换停止旧轮询并清理不兼容缓存。

## Phase 5：验收与发布

- [ ] Task 11：完成 E2E、安全、隐私和可访问性验证。
- [ ] Task 12：关闭 2.5.0 发布门槛。

### 最终门槛

- [ ] 单调用、多步骤、重试、清理、并发、失败、取消、缺失 Run E2E 通过。
- [ ] 套件/用例后续改名不改变历史快照显示。
- [ ] 同 URL 不同连接、跨项目、跨套件和伪造 Run ID 测试通过。
- [ ] 已知秘密不会进入 URL、普通日志、Toast、埋点、新表或默认导出。
- [ ] zh-CN/en-US、键盘、焦点、读屏状态、缩放和浅色/深色通过。
- [ ] 现有 SQLite 数据无损升级，已发布迁移字节不变。
- [ ] source/dist 迁移一致。
- [ ] `npm run verify` 通过。
- [ ] 发布制品验证通过。
- [ ] `npm pack --dry-run --json` 通过。
- [ ] `git diff --check` 通过。
- [ ] 无开放 Critical/Required 审查问题。
- [ ] 人工确认并批准 2.5.0 发布。
