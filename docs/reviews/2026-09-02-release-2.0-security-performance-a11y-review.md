- Real loopback MCP fixtures now reject incorrect expected request headers with HTTP 401.
- None/custom Header, literal Bearer, environment-resolved Bearer/Header, and OAuth token flows pass against the authenticated fixture.
- OAuth credentials remain process-local and are selected by connection ID. Same-URL connection isolation remains covered by the existing runtime and replay tests.
- Existing export tests confirm credentials, resolved secrets, profile secrets, Tab view state, and unrelated Server data do not enter default Server exports.
- QuickJS sandbox tests confirm no Node, filesystem, browser, arbitrary network, dynamic import, or dynamic code-constructor access; secret values remain blocked/redacted in arguments and durable logs.
- `npm audit --omit=dev --audit-level=high` reports 0 vulnerabilities.

Evidence: `src/server/connections/__tests__/streamable-session.integration.test.ts`; connection/runtime/export/workflow focused suites.
