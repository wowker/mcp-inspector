> 2.0.5 是 Tool 调试工作区的信息层级与标题一致性修复版本。它不改变 Server 连接状态、
> Tool Tab 身份、Run 生命周期、认证上下文、SQLite schema 或 API 契约。

## 1. 目标与非目标

目标：为顶部 Server 页签提供紧凑操作菜单；把调试布局预设收纳到右上角齿轮“设置”；消除同一 Tool Tab 序号因括号或空格差异产生的视觉重名。

非目标：关闭 Server 页签不会断开 Server；设置弹层不新增布局持久化字段；不自动合并、删除或重排已有 Tool Tab。

## 2. 用户流程

1. 用户点击顶部 Server 页签右侧的省略号，打开操作菜单。
2. 选择“关闭 Server 页签”仅移除当前工作区上下文；Server 的真实连接状态保持不变。
3. 在 Tool 调试顶部右侧点击齿轮“设置”，打开调试配置弹层。
4. 选择“参数优先”“均衡”或“结果优先”，复用原有 Split Pane 比例与按 Tab 保存机制。
5. 同一 Tool 打开多个 Tab 时，标题依次使用 `Tool 名称`、`Tool 名称 （2）`、`Tool 名称 （3）`。

## 3. 状态模型与身份边界

- Server 菜单状态只属于对应 `connectionId`；关闭操作不调用 disconnect API。
- 设置弹层是临时 UI 状态，不进入 browser storage 或数据库。
- 布局值仍写入当前 `tabId` 的 `viewState.splitRatio`，不会污染其他 Server 或 Tab。
- Tab 标题分配仍限定在 `projectId + connectionId + toolName` 范围；Tab ID 保持不变。

## 4. 标题重名根因与修复

原分配器按完整标题字符串判重，并只生成半角 `Tool (2)`。历史数据或手动标题中的全角括号、不同空格会被视为不同标题，因此相同序号可能并存。

修复后先解析标题的语义序号：半角/全角括号和可选空格都占用同一序号；新标题只输出 `Tool （n）` 这一种规范格式。客户端 Tool 意图已有串行队列和单次消费回归测试，本次没有改变该路径。

## 5. UI、键盘与可访问性

- 菜单使用省略号图标，设置使用 Phosphor 齿轮图标；纯图标按钮都有本地化可访问名称和 Tooltip。
- Server 菜单与设置弹层支持 Escape、点击外部关闭；键盘关闭后焦点返回触发按钮。
- 设置弹层打开后焦点进入当前布局选项，选中布局后关闭并返回齿轮按钮。
- 所有新增文案同时提供 `zh-CN` 与 `en-US`。

## 6. 安全、兼容与迁移

- 不新增依赖、API、SQLite migration 或 secret 展示路径。
- 标题解析只作用于同一 Tool 的序号分配；自定义的非序号标题不被改写。
- 已有半角或无空格标题仍可正常显示和关闭；后续新建不会重复占用其语义序号。
- 本版本可通过回滚前端与标题分配代码恢复，不需要数据降级。

## 7. 自动化测试

- Server 工作台测试覆盖菜单打开、Escape 关闭、焦点返回、关闭页签且不调用断开连接。
- Tool 调试测试覆盖设置入口、弹层关闭、三种布局预设与按 Tab 隔离。
- TabService 回归测试覆盖规范标题输出及半角/全角、空格差异的序号去重。
- 完整交付门槛为 typecheck、全部 Vitest、生产 build 和 Playwright E2E。
- 2026-09-03 已通过 `npm run verify`：typecheck、118 个 Vitest 文件（855 项测试）、生产构建和 7 项 Playwright E2E 全部通过。

## 8. 发布与回滚条件

- 若关闭页签会断开连接、布局设置串 Tab、同一语义序号仍重复、键盘无法关闭浮层或完整门禁失败，则停止发布。
- 本版本没有不可逆数据变化，可回滚应用代码。
