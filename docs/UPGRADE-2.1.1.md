# MCP Inspector 2.1.1 更新说明

## Tool 调试执行历史

- 执行历史采用“记录列表 + 只读详情”布局。选择记录只加载该次调用的参数、响应结果和追踪信息，不修改当前调试 Tab。
- 详情提供“加载到调试”显式操作；只有用户触发该操作后，历史参数与响应才进入当前调试视图。
- 支持删除单条执行记录，以及清空当前 Tool Tab 的执行历史，两种操作都需要二次确认。
- 清空操作按项目、连接、Tab 和 Tool 身份精确隔离；运行中、已固定及被测试报告或脚本执行引用的记录会保留。

## 工作台状态保留

- Tools 调试、自动化测试和测试套件在首次进入后保持挂载。
- 在三个模块之间切换时，保留当前 Tool Tab、未提交参数、当前子视图、测试用例草稿、测试套件草稿和选择状态。
- 切换项目或 Server 时仍遵循既有身份隔离，不跨项目或连接复用状态。

## 回归验证

- 覆盖历史记录只读查看与显式加载的行为边界。
- 覆盖单条删除、精确范围清空及受保护记录保留。
- 覆盖 Tools 调试、自动化测试和测试套件三方切换后的内容恢复。
